# Uniform elves 

Deployment of a festive unity-webgl work project developed for fun with a friend at Uniform communications.  
Displayed on the main [Uniform](https://uniform.net/) home page for a brief time.  

## Easter egg
Click the music note button multiple times until the elves start to change colour, now you can use the left and right mouse buttons to randomise until you find your favourite colour scheme.  

Click the image below or [here](https://joethew.github.io/Uniform_Christmas/) to open the interactive page.
